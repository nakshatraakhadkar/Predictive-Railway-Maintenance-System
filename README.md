🚄 Predictive Railway Maintenance System
🔍 Overview
This project is an end-to-end Machine Learning system designed to shift railway maintenance from reactive to proactive . By analyzing 5 years of historical operational data (2019-2024), the system predicts infrastructure failures before they cause major delays.

It includes a LightGBM inference engine for real-time predictions and a Streamlit dashboard for operational staff.

🎯 Key Performance Indicators (KPIs)
Cause Classification (F1-Score): 0.39 (Macro-averaged) — Successfully identifies rare, high-impact accidents.

Duration Estimation (MAE): 189 minutes — Provides realistic recovery time estimates for resource planning.

🛠️ Tech Stack
Core Logic: Python 3.11, Polars (High-performance data manipulation)

ML Engine: LightGBM (Gradient Boosting)

App/Dashboard: Streamlit

Deployment: Docker Containerization
